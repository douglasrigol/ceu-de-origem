# ceu-de-origem
Landing page conceitual de uma marca fictícia que transforma uma data e um lugar em um mapa do céu. Tem um preloader em que o sol marca o progresso real do carregamento, constelações animadas, formulário com validação e prévia ao vivo do mapa, galeria com efeito de scroll e modelos 3D. Construída com React e Vite.
